## 1. 设计结论与视觉基准

粮掌柜编排区采用 A 的无全息投影版本，使用现有七位角色 IP、分层立体底座、协作数据流与业务状态标注，增强空间感并清楚表达专业分工。

视觉基准为本次交互预览 `.superpowers/brainstorm/59868-1789458900/content/orchestration-without-holograms-v7.html` 中的 A 方向、全息层关闭状态。该目录已被项目忽略，预览作为本地参考，不作为正式页面的运行依赖。

保留：

- 粮掌柜居中、六位小二围绕的固定站位。
- 完整 IP、前后尺度关系、脚下阴影、分层底座与环形刻度。
- 克制的角色浮动、轻微鼠标视差、状态驱动的数据流。
- 姓名、办理状态、简短结论与点击查看详情。

去除：业务全息屏、环形幕墙、投影光束、悬浮编排屏与共享记忆投影。正式页面不提供 A/B/C 选择或全息开关；这些属于设计预览工具。

## 3. 编排状态与交互

继续以 `CollaborationSnapshot` 和可选 `liveRuns` 驱动画面，优先使用实时状态覆盖快照状态。

| 状态 | 舞台表现 |
| --- | --- |
| 未参与 | IP 降低亮度，显示待命，无活动数据流；采购模式下沿用禁止点击的现有行为 |
| pending | 显示待启动，底座保持低亮，无活动数据流 |
| running | 激活对应底座，沿中央到角色方向显示数据流 |
| completed | 状态切换时短暂回传光点，随后稳定绿色；初次加载已完成任务不重播历史完成动画 |
| completed_with_objection | 真正提出异议的小二与路径显示琥珀色，不把仅被关联的其他小二标成异议 |
| failed | 失败节点显示红色与结果缺失文字，停止活动数据流 |

动画不改变业务状态，也不延迟用户操作。已完成结果在抽屉中阅读；舞台保留一句简短结果，长文本截断，防止遮挡角色和连线。

点击角色沿用现有 `onSelectAgent`，打开已有结果抽屉。节点使用可聚焦按钮，支持键盘操作和选中反馈。鼠标视差不影响点击区域和文字可读性。

## 4. 实现边界

按已确认预览的效果采用现有 React、SVG 和 CSS 实现，不新增渲染依赖。人物继续使用现有 IP 图片；舞台通过分层造型、尺度、遮挡、阴影与视差呈现空间。

- `SpatialAgentStage.tsx`：组合舞台环境、中央 IP 和各小二节点，保留现有属性接口。
- `AgentPod.tsx`：用完整 IP、底座和简短标注替换大面积矩形卡片，保留可访问性与选择行为。
- `AgentFlowSvg.tsx`：维护与角色一致的坐标和路径，区分派发、回传、静止及异常表现。
- `zhanggui.css`：舞台分层、主题色、动效和窄屏样式。
- `purchase.css`：必要时调整固定画布的比例和容器高度，避免节点裁切。

舞台同时服务 `PurchaseCockpit` 与 `MissionCockpit`。后端、采购流程、决策确认、结果抽屉和企业知识库逻辑不在本次改造范围内。若需要抽出静态舞台背景组件，只围绕本次展示做小范围拆分。

## 5. 布局与性能

角色、底座、连线和视差共用舞台坐标与缩放，禁止分别缩放造成连接错位。按脚底纵向位置组织遮挡顺序，保证后排角色不会覆盖前排节点。

桌面保持完整舞台。窄屏优先保证文字、点击和结果可读，可收敛为紧凑角色列表；不强行把完整舞台缩成难以阅读的小图。

页面隐藏时暂停循环动画，遵循减少动态效果偏好，触屏设备关闭鼠标视差。图片加载失败时保留角色名称与可点击的后备标识。动画清理随任务切换和组件卸载执行，避免旧任务效果残留。
